## 1. สร้างบัญชีเจ้าหน้าที่

1. Supabase Dashboard → Authentication → Users → **Add user** → **Create new user**
2. ใส่อีเมลและรหัสผ่าน แล้ว**ติ๊ก Auto Confirm User** (ถ้าไม่ติ๊ก จะล็อกอินไม่ได้จนกว่าจะยืนยันอีเมล)
3. SQL Editor → วางแล้วกด Run (แก้อีเมลและชื่อให้ตรง)

```sql
insert into staff (id, full_name)
select id, 'ชื่อเจ้าหน้าที่'
from auth.users
where email = 'อีเมลที่สร้างในข้อ 2'
on conflict (id) do nothing;
```

ถ้าล็อกอินไม่ได้ หน้าเข้าสู่ระบบจะบอกสาเหตุ: ไม่มีบัญชีหรือรหัสผิด / ยังไม่ยืนยันอีเมล / ยังไม่มีสิทธิ์เจ้าหน้าที่ (ยังไม่ได้รัน SQL ในขั้นที่ 3)

## 2. AI วิเคราะห์ภาพ

คีย์ที่ใส่ไว้ใน Vercel ชื่อ `KIE_API_KEY` เป็นคีย์ของ Anthropic (ขึ้นต้น `sk-ant-`) ไม่ใช่คีย์ของ Kie.ai ระบบดูจากรูปแบบคีย์แล้วเรียก Anthropic โดยตรง โมเดล `claude-sonnet-5-5`
(`claude-sonnet-4-5` ถูกปลดแล้ว เรียกจะได้ 404 และรุ่นปัจจุบันไม่รับ `tool_choice` แบบบังคับ จึงใช้ `auto` + `strict`)

- เปลี่ยนคีย์: แก้ค่า `KIE_API_KEY` หรือเพิ่ม `ANTHROPIC_API_KEY` (ถ้ามี จะใช้ตัวนี้ก่อน) ใน Vercel → project `ai-tool-fix` → Settings → Environment Variables แล้ว deploy ใหม่ ถ้าไม่ deploy ใหม่ คีย์จะไม่มีผล
- ถ้าภายหลังใช้คีย์ของ Kie.ai จริง (32 ตัวอักษร) ระบบจะเรียก `https://api.kie.ai/claude/v1/messages` แทน
- ตรวจ: แจ้งซ่อมพร้อมรูป 1 รายการ แล้วเปิดติดตามสถานะ ต้องเห็นชื่ออุปกรณ์และประเภทงาน ถ้าว่าง ดู Vercel → Logs ค้นคำว่า `Photo analysis failed` หรือ `Kie key check`

## 3. ฐานข้อมูลหยุดเอง (Supabase แพ็กเกจฟรี)

แพ็กเกจฟรีจะหยุดโปรเจกต์เมื่อไม่มีการใช้งานประมาณ 7 วัน อาการคือ เลือกหน่วยงานไม่ได้ ติดตามสถานะขึ้น "ระบบขัดข้อง" และล็อกอินไม่ได้ พร้อมกันทั้งหมด

- ป้องกัน: workflow `.github/workflows/keep-alive.yml` เปิดหน้าแจ้งซ่อมของ ai-tool-fix.vercel.app ทุก 3 วัน (ส่งคุกกี้บุคคลภายนอกไปด้วย เพราะถ้ายังไม่เลือกประเภทผู้ใช้ หน้าจะพาไป /start โดยไม่แตะฐานข้อมูล) ถ้าฐานข้อมูลไม่ตอบ run จะขึ้นสีแดงและ GitHub ส่งอีเมลแจ้ง
- แก้: Supabase Dashboard → เปิดโปรเจกต์ → **Restore project** รอประมาณ 3–5 นาทีกว่าข้อมูลจะกลับมา
- GitHub จะปิด workflow ที่ตั้งเวลาไว้เองถ้า repo ไม่มี commit 60 วัน ถ้าจะใช้งานต่อหลังจากนั้นให้เปิดใหม่ที่แท็บ Actions

## 4. Deploy

- เว็บหลัก `ai-tool-fix.vercel.app` deploy อัตโนมัติทุกครั้งที่ push ขึ้น `main` **จึงต้องรัน migration ใหม่ใน Supabase ก่อน push เสมอ** ไม่งั้นหน้าเว็บจะเรียกคอลัมน์หรือตารางที่ยังไม่มี
- เว็บสำรอง `ai-tool-fix-two.vercel.app` ต้องสั่งเอง

```bash
npx vercel deploy --prod --yes
```
