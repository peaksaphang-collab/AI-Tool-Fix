Pain Points

ปัญหาของระบบเดิม

📝 กรอกเยอะ

ผู้แจ้งต้องพิมพ์อธิบายอาการเสียเอง ทั้งที่บางครั้งไม่รู้ว่าอุปกรณ์ชื่ออะไร ทำให้แจ้งช้าและข้อมูลไม่ครบ

❓ ไม่รู้สถานะ

แจ้งไปแล้วเงียบ — ผู้แจ้งไม่รู้ว่าซ่อมเสร็จหรือยัง ช่างเปิดมาก็ไม่เห็นภาพรวมว่าเหลืองานอะไร

📊 ดูข้อมูลยาก

รายงานเป็นกราฟวงกลม/แท่งแบบเดิม ต้องกดดูทีละหน้า ไม่มีสรุปภาพรวมที่เข้าใจได้ในหน้าเดียว

Design Concept

แนวคิด: Less is More

ผู้แจ้ง — ทำแค่ 3 อย่าง

  • ถ่ายรูปสิ่งที่เสีย 1 รูป
  • เลือกอาคาร + ห้อง จากตัวเลือก (ไม่ต้องพิมพ์)
  • กดส่ง — จบ ที่เหลือ AI จัดการ

เจ้าหน้าที่ — เห็นทุกอย่างในหน้าเดียว

  • บอร์ดแบ่ง 2 ฝั่ง: ยังไม่เสร็จ / เสร็จแล้ว
  • เคสใหม่เด้งเตือนอัตโนมัติทันที
  • Dashboard สรุปรายวัน · รายเดือน · รายปี

AI วิเคราะห์ให้เอง

ไม่ต้องพิมพ์อธิบายอาการ ไม่ต้องรู้ชื่ออุปกรณ์ — ระบบวิเคราะห์จากรูปให้อัตโนมัติ

AI Logic

AI วิเคราะห์รูปอย่างไร

ขั้นตอน

  • รูปถูกส่งไปยัง Claude Vision API ฝั่งเซิร์ฟเวอร์ (key ไม่หลุดถึงเบราว์เซอร์)
  • AI ตอบกลับผ่านโครงสร้างบังคับ (tool schema): อุปกรณ์ · อาการเสีย · ความมั่นใจ 0–1
  • ผลวิเคราะห์บันทึกคู่กับรายการแจ้งซ่อมทันที

ตัวอย่างผลลัพธ์

รูปแอร์มีน้ำหยด →

  • อุปกรณ์: เครื่องปรับอากาศ
  • อาการ: มีน้ำรั่วซึมบริเวณหน้ากากแอร์
  • ความมั่นใจ: 0.92

ถ้า AI วิเคราะห์ไม่ได้ ระบบยังรับแจ้งตามปกติ — เจ้าหน้าที่ระบุเองภายหลัง (ไม่มีทางแจ้งไม่เข้า)

Staff View

บอร์ดสถานะเรียลไทม์ + แจ้งเตือนอัตโนมัติ

🔀 แบ่ง 2 ฝั่งชัดเจน

"ยังไม่เสร็จ" กับ "เสร็จแล้ว" อยู่หน้าเดียวกัน ไม่ต้องเลื่อนกดดูทีละรายการ

🔔 เตือนทันที

เคสใหม่เด้งแจ้งเตือนบนจอทุกเครื่องที่เปิดอยู่ งานค้างเกิน 24 ชม. ขึ้นป้าย "ค้างนาน" สีแดง

👥 ใช้พร้อมกันได้

เจ้าหน้าที่หลายคนเปิดพร้อมกัน — คนหนึ่งกด "ซ่อมเสร็จ" ทุกจออัปเดตทันทีผ่าน Supabase Realtime

Database Design

โครงสร้างฐานข้อมูล (PostgreSQL)

ตารางเก็บอะไรจุดเด่น
buildings / roomsอาคารและห้องทั้งหมดเป็นตัวเลือกใน dropdown — ระบุตำแหน่งแม่นกว่า GPS
service_typesประเภทงานซ่อม 5 ประเภทรหัสตรงกับระบบเดิม 1:1 — ย้ายข้อมูลเก่าได้ทันที
reportsแจ้งซ่อม + ผล AI + ความเร่งด่วน + ผู้รับผิดชอบอัปเดตแล้วกระจายเรียลไทม์ทุกหน้าจอ
report_status_historyประวัติการเปลี่ยนสถานะบันทึกอัตโนมัติด้วย trigger — ใช้ทำ Timeline
staffบัญชีเจ้าหน้าที่ผูกกับระบบล็อกอิน Supabase Auth

ความปลอดภัย: Row Level Security ทุกตาราง — คนทั่วไป "ส่งแจ้งซ่อมได้แต่อ่านข้อมูลไม่ได้" เฉพาะเจ้าหน้าที่ที่ล็อกอินเท่านั้นที่เห็นข้อมูลทั้งหมด รูปเก็บใน private bucket เปิดดูผ่านลิงก์ชั่วคราวเท่านั้น

Technology

โปรแกรมและเทคโนโลยีที่ใช้

Frontend + Backend

  • Next.js 16 — เว็บเฟรมเวิร์กตัวเดียวจบทั้งหน้าเว็บและ API (Server Actions)
  • Tailwind CSS + shadcn/ui — ดีไซน์คลีน ทันสมัย responsive ทุกจอ

ฐานข้อมูล + AI

  • Supabase — PostgreSQL + ล็อกอิน + เก็บรูป + Realtime ในบริการเดียว (เริ่มได้ฟรี)
  • Claude Vision API — วิเคราะห์รูปภาพว่าอุปกรณ์อะไรเสีย

ทำไมเลือกชุดนี้

ทุกตัวมี free tier พอสำหรับโครงงาน · deploy ง่าย (Vercel กดเดียว) · เป็น stack ที่บริษัทจริงใช้กันแพร่หลาย — นำไปต่อยอดหรืออธิบายในการสอบได้เต็มปาก

System Requirements

ความต้องการของระบบ — พัฒนาแล้ว 20/20 ข้อ

ผู้แจ้ง (FR-01–07)

  • ถ่ายรูป + เลือกอาคาร/ห้อง ไม่ต้องพิมพ์
  • AI ระบุอุปกรณ์ อาการ หมวดหมู่ ความเร่งด่วน
  • AI ล่มก็ยังแจ้งได้ (ไม่มีทางแจ้งไม่เข้า)

เจ้าหน้าที่ (FR-08–14)

  • สถานะ 4 แบบ รวม "ดำเนินการไม่ได้"
  • เรียลไทม์ + แจ้งเตือนอัตโนมัติ + ป้ายค้างนาน
  • มอบหมายผู้รับผิดชอบ, เรียงตามความเร่งด่วน

รายงาน (FR-15–20)

  • KPI · Kanban · Timeline · Heatmap · ปฏิทิน
  • สรุปรายวัน/เดือน/ปี เทียบช่วงก่อนหน้า
  • รายงานตามประเภทบริการ + รายคน (ตามระบบเดิม)

Non-functional: responsive ทุกอุปกรณ์ · ฟอนต์ไทยไม่เพี้ยนทุก OS · RLS ทุกตาราง · เริ่มใช้ฟรี (free tier)

UX/UI Design

ออกแบบจากคำถามเดียว: "ตัดอะไรออกได้อีก"

Mobile-first

ปุ่มถ่ายรูปเปิดกล้องหลังทันที ฟอร์มเหลือ 3 จุดสัมผัส ทุกหน้า responsive ขนาดไม่เพี้ยนทุกจอ

สีสื่อความหมายเดียว

เหลือง=รอ น้ำเงิน=กำลังซ่อม เขียว=เสร็จ แดง=วิกฤต — ใช้เหมือนกันทุกหน้า พร้อมข้อความกำกับเสมอ (รองรับตาบอดสี)

ฟอนต์ไทยทุกแพลตฟอร์ม

IBM Plex Sans Thai + fallback ลึกถึงฟอนต์ระบบของ Windows/macOS/Android — ไม่มีสี่เหลี่ยมทุกกรณี

Component เดียวกันทั้งแอป (shadcn/ui) · ไม่มีของตกแต่งไร้หน้าที่ · ทุกอย่างที่กดได้ต้องเห็นผลทันที — รายละเอียดอยู่ใน docs/UX-UI-DESIGN.md

Summary

สิ่งที่ระบบนี้ตอบโจทย์

✅ ครบตามโจทย์

  • ลดขั้นตอนกรอก — ถ่ายรูป + เลือกห้อง จบ
  • AI วิเคราะห์อุปกรณ์ อาการ หมวดหมู่ 5 ประเภท + ความเร่งด่วน 4 ระดับ
  • สถานะ 4 แบบเห็นในหน้าเดียว + เตือนอัตโนมัติ + มอบหมายงานรายคน
  • Dashboard สรุปรายวัน/เดือน/ปี + รายงานตามประเภท/รายคน โดยไม่ใช้กราฟวงกลม/แท่ง

🚀 ต่อยอดได้

  • แจ้งเตือนผ่าน LINE / อีเมล
  • มอบหมายงานให้ช่างรายคน
  • สแกน QR ประจำห้องเพื่อแจ้งซ่อมเร็วขึ้น
  • รายงาน PDF อัตโนมัติรายเดือน
